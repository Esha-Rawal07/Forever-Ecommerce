# Forever - MERN Stack E-Commmerce Web Application
A Modern Full-Stack E-Commerce Web Application Built Using the MERN Stack With Secure Online Payment Integration.

# Tech Stack
* Frontend: React.Js, Vite ,HTML, CSS / Tailwind CSS, JavaScript
* Backend: Node.Js, Express.Js
* Database: MongoDB,Mongoose
* Payments: Stripe & Razorpay
* Authentication: JWT
* API : REST API

# Features
* User Registration and Login
* Product browsing and Search
* Shopping Cart and Checkout
* Online Payments with Stripe & Razorpay
* Order Placement and Order Tracking
* Responsive Design
* Admin Panel for Managing Products and Orders

# Project Structure
* Frontend - Customer-Facing Website
* Backend - Server and API
* Admin - Admin Panel
